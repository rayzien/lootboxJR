# Owoloot Helper

Welcome to the **Owoloot Helper** repository! 

This project was built entirely for **educational purposes**, exploring backend development with FastAPI, dynamic web interfaces with modern glassmorphism UI, and colorful logging configurations. 

## Features
- **FastAPI Backend:** Lightning fast backend API routing.
- **Beautiful UI:** Dynamic HTML, CSS, and JS with fluid animations and responsive design.
- **Custom Logger:** ANSI-based colorful console logs.
- **Command Configurations:** Structure for extending functionality with commands.

## How to Run

1. **Install dependencies:**
   ```bash
   pip install fastapi uvicorn
   ```

2. **Start the server:**
   ```bash
   python main.py
   ```

3. **Explore the app:**
   - Home: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
   - Settings: [http://127.0.0.1:8000/settings](http://127.0.0.1:8000/settings)
   - Configuration: [http://127.0.0.1:8000/config](http://127.0.0.1:8000/config)
